UpPost

A personal tool that sends my own videos and photos to my TikTok drafts, so I can finish and publish them in the TikTok app.

Permission requested: video.upload (Content Posting API, Upload mode). UpPost only creates drafts in the account owner's inbox. It never publishes on its own.

How it works

  1. Select Login with TikTok and approve the permission on TikTok.
  2. TikTok returns to the callback page with an authorization code.
  3. UpPost uses the code to get an access token and uploads a video as a draft.
  4. The owner opens the TikTok app, edits the draft and publishes it manually.

Your data

UpPost is used only by its owner for the owner's own account. It does not collect or share data about anyone else.
